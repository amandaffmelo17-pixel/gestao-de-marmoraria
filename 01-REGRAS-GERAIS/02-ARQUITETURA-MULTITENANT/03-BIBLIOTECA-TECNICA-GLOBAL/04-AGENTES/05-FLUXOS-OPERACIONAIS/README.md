# GESTÃO DE MARMORARIA — FLUXOS OPERACIONAIS
## VERSÃO 1.0

### FLUXO PRINCIPAL COMPLETO
1. ✅ Cliente solicita → 2. Orçamento → 3. Aprovação → 4. Gera Pedido → 5. Levantamento → 6. Liberação Técnica → 7. Produção → 8. Qualidade → 9. Expedição → 10. Instalação → 11. Aceite → 12. Financeiro

---

### 📋 DETALHAMENTO DE CADA ETAPA

#### 1. ORÇAMENTO
- Dados do cliente, obra, ambiente
- Lista de peças, medidas, materiais, acabamentos
- Cálculo de área + metro linear + materiais + mão de obra
- Condição comercial, prazo de entrega, validade
- Enviado para aprovação do cliente

#### 2. APROVAÇÃO
- Cliente aceita / solicita ajustes / recusa
- Aprovado → gera **PEDIDO** com número próprio
- Recusado → arquiva com motivo

#### 3. PEDIDO
- Número sequencial da empresa
- Vinculado ao orçamento aprovado
- Dados fiscais, condição de pagamento, entrada
- Status: Pendente → Liberado → Em Produção → Pronto → Concluído

#### 4. LEVANTAMENTO TÉCNICO
- Visita ao local → confirma medidas reais
- Pontos de atenção: ralos, torneiras, tomadas, luz
- Valida viabilidade → ajusta se necessário
- Libera ou bloqueia produção

#### 5. PRODUÇÃO
- Programa corte nas chapas disponíveis
- Rastreabilidade da chapa usada
- Etapas: Corte → Colagem → Usinagem → Polimento
- Tempo previsto × Tempo realizado
- Registro de perdas

#### 6. CONTROLE DE QUALIDADE
- Inspeção visual e dimensional
- Verifica: medidas, espessura, bordas, junções, acabamento
- Aprovado → segue
- Reprovado → retrabalho ou nova fabricação

#### 7. EXPEDIÇÃO
- Conferência peça por peça com romaneio
- Embalagem adequada
- Registro de saída
- Entregador assina recebimento

#### 8. INSTALAÇÃO
- Agenda data e horário
- Execução no local
- Conferência final
- Cliente assina aceite

#### 9. FINANCEIRO
- Emite parcelas conforme condição
- Registra recebimentos
- Controla vencidos e a vencer
- Emite NFS-e

- **Assistência Técnica:** Solicitação → Avaliação → Causa → Solução → Execução → Aceite
